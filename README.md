# Samanali & Chamod Wedding Invitation

An interactive wedding invitation built with Next.js, React, Tailwind CSS, Framer Motion, and GSAP.

## Getting Started

1. Run `npm install`
2. Run `npm run dev`
3. Open `http://localhost:3000` (or `/invite`)

Create an optimized production build with `npm run build`, then run it with `npm start`.
